## 第一步：第一原理评估

| 问题 | 结论 |
|---|---|
| 用户可见症状 | 工作台只有超时名单和禁用词命中，管理者看不到「明天先跟谁、他在问什么、有没有风险」 |
| 根因 | 现有统计是会话/按日效率，不是联系人经营状态；诊断报告依赖模型且不能当每日待办 |
| 不做会怎样 | 仍可看效率与明细，但复盘停留在「慢不慢」，指挥不了跟进名单 |
| 收益 | 管理人员打开首页即得到可行动名单；规则不耗模型费用 |
| 成本 | 首页改版；规则误伤（营销文案、单向客户消息）需可解释、可改词表 |
| 与一期边界 | **不是**人物画像、六维评分、客服排名。只做联系人级规则看板 |
| 结论 | **做。** 一期增补 P1，不替代效率页和诊断报告 |

## 第二步：技术方案（已确认并落地）

### 目标

首页改为好友雷达：每个真实客户一行，展示状态、主诉求、标记，点进对应会话。

### 涉及模块

| 层 | 位置 |
|---|---|
| 规则 | `lingxi-cs-data/backend/app/engine/radar.py` |
| 接口 | `GET /api/radar` |
| 页面 | 原工作台 → 好友雷达（`frontend/src/views/Dashboard.vue`） |
| 过滤 | 复用公众号/系统会话剔除（`contact_is_official`）；雷达额外排除 `*@weclaw` |
| 禁用词 | 读 `hit_records`（由规则扫描写入，不在打开雷达时重扫词表） |

### 不做什么

- 不调用客户模型、不写雷达结果表、不定时后台刷新
- 不做画像标签云、成交漏斗人工标注、自定义评分
- 不自动发微信、不改聊天原文

### 回滚

恢复工作台超时/禁用词双表即可；规则集中在 `radar.py`，删除该页与 `GET /radar` 不影响同步和效率统计。

## 第三步：规则口径（需求正文）

分析对象是**联系人**（一个微信客户），不是切分后的单段会话。点进去打开该客户**最近一段会话**。

### 3.1 谁出现在雷达

同时满足：

1. 本地已有会话和消息；
2. 不是公众号/系统会话（与会话明细同一套噪音规则）；
3. 不是本机助手类账号（微信号以 `@weclaw` 结尾）；
4. 若顶栏选了查看范围：该客户在范围内**至少有一条消息**。未选日期则看全部已同步客户。

范围内决定「名单里有谁」；**状态、诉求、标记仍按该客户全部已同步消息计算**（避免只看一天把跟进人误判成新询盘）。

### 3.2 状态（四选一，自上而下命中即停）

超时阈值默认 180 秒，与系统设置「超时阈值」相同。沉寂默认 7 天。

| 状态 | 条件 |
|---|---|
| 待回复 | 该客户最后一条消息的发送方是客户 |
| 沉寂 | 最后一条不是客户，且距现在 ≥ 7 天 |
| 新询盘 | 最后一条不是客户，距现在 < 7 天，客户文本条数 ≤ 3，且首末消息间隔 ≤ 7 天 |
| 跟进中 | 其余（有来有回、仍在 7 天内） |

**超时未回**是标记，不是独立状态：在「待回复」且等待已超过超时阈值时打上。

### 3.3 主诉求与角色

只扫**客户**文本，从新到旧，命中第一条规则即停。不调用模型。

| 展示名 | 客户原文含子串之一 |
|---|---|
| 退费 | 退费、退款、退钱、退课时 |
| 价格 | 多少钱、报价、价格、费用、优惠、便宜 |
| 档期 | 预约、档期、什么时候、几点、哪天、能不能来 |
| 效果 | 效果、质量、好不好、靠谱 |
| 投诉 | 投诉、举报、工商、律师、差评 |
| 课时 | 课时、上课、课程 |

均未命中则主诉求显示「—」，下方仍展示客户最近一句摘录（去掉 `[链接]` 等占位，最长 36 字）。同一句里「退费」优先于「价格」「课时」。

**身份倾向**（规则推断，接口仍返回 `role` 字段；好友雷达首页不展示，避免与微信标签混淆）：扫对方全部文本，先机构后家庭后个人。

| 展示名 | 对方原文含子串之一 |
|---|---|
| 机构 | 我们学校、校长、班级、校本、教研、同事、公司、单位、部门 |
| 家庭 | 孩子、小孩、家长、作业、我家娃、我家、家人、老公、老婆 |
| 个人 | 我自己、我报名、我来上课、个人用、我自己学 |

均未命中则 `role` 为「—」。行业定制可在场景包中扩展词表或改展示名。

### 3.4 标记（可并存）

| 标记 | 条件 |
|---|---|
| 风险 | 该客户全部消息（含客服）出现：退费、退款、投诉、举报、律师、工商、差评、骗子、假的、报警 |
| 退费前兆 | 客户文本按时间顺序：先出现效果/质量/好不好/靠谱/没效果/没用，之后再出现退费/退款/投诉/举报 |
| 超时未回 | 状态为待回复，且等待秒数 > 超时阈值 |
| 已发未回 | 最后一条是客服，且该条含报价/价格/优惠/多少钱/费用/课时包/方案，或类型为链接/文件（含 `[链接]` `[文件]` 占位） |
| 承诺未兑 | 客服消息中最近一次含：明天、稍后、回头给你、帮你问、帮你申请、给你方案、跟进一下、确认后、回复你；且该句之后**没有**新的客服消息；且（客户后又说话，或距该承诺已超过 24 小时） |
| 决策中 | 客户文本含：问问、再考虑、商量一下、跟领导确认、跟校长确认、再看看、考虑一下 |
| 禁用词 | 该客户任一会话在 `hit_records` 中有禁用词命中 |
| 老客 | 该客户首末消息间隔 ≥ 30 天 |

### 3.5 排序

优先级从高到低：风险或退费前兆 → 超时未回 → 待回复 → 已发未回 → 承诺未兑 → 决策中 → 新询盘；沉寂靠后。同级按最近消息时间升序（较早的在前）。

### 3.6 触发与更新时机

| 数据 | 何时计算 | 何时会变 |
|---|---|---|
| 状态、主诉求、角色、风险、超时未回、已发未回、承诺未兑、决策中、退费前兆、老客 | **打开或刷新好友雷达时当场计算**，不落库 | 新同步了聊天；或仅因时间流逝后再刷新 |
| 名单范围 | 同上，并受顶栏日期影响 | 改查看范围后重新请求 |
| 禁用词标记 | 读规则扫描结果 | **微信同步成功后自动扫描**，或效率统计页「重新统计」。只改词表不扫描则雷达上的禁用词不更新 |
| 诊断报告 | 用户点「发起分析」 | 与雷达无关，不写雷达字段 |

日常路径：`微信同步 → 打开/刷新好友雷达`。不要求先跑诊断。

页面顶栏五个数字（好友 / 待回复 / 已发未回 / 风险 / 沉寂）可筛选列表；数字始终是当前日期范围内的全量汇总。风险数字含退费前兆。
