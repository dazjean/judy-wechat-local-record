# Judy 桌面应用说明

> 适用：Judy 商用 Mac 包 · 与灵犀商用部署包同一构建口径（Tauri 壳 + 内嵌 Python + Nuitka 模块）

## 是什么

**Judy.app** 是交付 zip 根目录的 macOS 桌面应用：双击后用 App 内嵌的 Python 启动本机服务（8090），并在窗口里打开界面。

不要只把 `.app` 拷到「应用程序」：业务模块、界面、授权和读取组件都在 App 内，但 `data/`、`logs/` 必须留在解压目录（写入会破坏签名）。

推荐布局：

```
Judy-1.0.0-macos-arm64-客户名/
├── Judy.app              ← 双击启动（backend / web / license / 脚本 / 读取组件都在 App 内）
├── install.sh
├── 使用说明.md
├── 微信读取初始化.app
├── data/
└── logs/
```

若必须把 `.app` 移走，在 `.app` **同级**创建文本文件 `JUDY_ROOT`，内容一行写解压目录的绝对路径；或设置环境变量 `JUDY_ROOT`。

## 安装

1. 解压到非 iCloud 占位目录
2. `bash install.sh`（整包 `xattr -cr` + ad-hoc `--deep` 签名）
3. 运行「微信读取初始化」
4. 双击该解压目录里的 **Judy.app**

当前版本未做 Apple 公证。若提示无法验证开发者：右键 → 打开。

## 退出

- **关窗口**：隐藏到托盘，本机服务继续。
- **退出 Judy**（托盘或 Cmd+Q）：停止 8090 服务。
- 系统设置里的「重启 Judy」：只重启服务，桌面壳保持。

## 与 Windows

Windows 桌面壳须在 Windows 上构建（与灵犀相同，Mac 不交叉编译）。在此之前可用开发脚本 `scripts/start.bat`。
