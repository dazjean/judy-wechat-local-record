# 使用说明

本系统产品名为「Judy」，副标题「本机微信会话分析」。授权绑定交付时约定的微信，复制安装目录给其他人无法使用。

## 启动前

1. 打开并登录约定的微信（Windows 建议 4.1.9.0）。
2. 解压到固定目录（不要放 iCloud / 网盘同步盘），在解压目录运行一次 `bash install.sh`。
3. 运行「微信读取初始化」。
4. 在 Finder 里双击 **Judy**。界面在应用窗口里打开。首次同步若弹出「想访问其他 App 的数据」，点允许即可。

关窗口会收到菜单栏托盘，后台服务继续。要从托盘或 Dock 选「退出 Judy」才会完全停止。系统设置里的「重启 Judy」只重启本机服务，窗口不用关。

若提示未授权或微信不符，请确认登录的是交付时约定的微信，不要使用别人拷贝来的安装包。

若为试用版，窗口顶部会显示剩余时间；到期后需更换正式授权才能继续使用。把正式授权文件放到 Judy 解压目录（与 Judy.app 同级）后点重试即可，不必重装。

若提示「已损坏」或无法打开：再跑一次 `bash install.sh`，弹窗点「完成」不要「移到废纸篓」；或右键 Judy.app → 打开。

## 日常使用

1. 打开「微信同步」，确认读取状态为已就绪，点「开始同步」。
2. 打开「客户雷达」，按待回复 / 报价后沉默 / 风险 / 沉寂看今天该跟谁；点客户进那条聊天。主诉求、角色和风险是规则算的，不用先跑诊断。
3. 在「会话明细」可搜索客户、按超时/禁用词筛选。
4. 在「效率统计」看首次/平均响应（分秒）和超时会话。
5. 在「系统设置」填写**我的微信昵称**、模型地址、模型名和 API Key。会话气泡会显示对方昵称和你的昵称，不再显示「客户 / 客服」。
6. 到「诊断报告」选择提示词后发起分析。可在「提示词」页编辑诊断报告提示词，或新增分析场景。

数据只保存在本机。不要把 API Key 发给实施人员以外的人。
