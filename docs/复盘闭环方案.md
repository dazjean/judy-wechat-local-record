# 复盘闭环方案

数据链路已经能把聊天读进来。本方案只补一件事：**从结论点进那条聊天**。

不做大屏、多账号权限、自动点开原图、语音转写。

## 闭环

```
同步微信 → 自动规则扫描 → 好友雷达 / 效率 / 诊断
                ↓ 点客户名或结论
         会话明细（选中该会话，展开消息）
```

跳转约定：`/conversations?id=<会话ID>`。可选 `flag=timeout|forbidden|missing_media`。

## 页面改动

| 页面 | 改什么 |
| --- | --- |
| 好友雷达 | 按联系人看状态、主诉求、风险/超时/承诺未兑/禁用词。点客户进最近一段会话。打开页面当场计算，不调模型 |
| 会话明细 | 搜客户、按标记筛、标记列。URL 带 id 时自动选中并拉消息 |
| 效率统计 | 时长分秒；超时清单可跳转 |
| 诊断分析 | 跟顶栏日期走；结论尽量带客户名和会话 ID，可点进聊天；旧结果没有 ID 则不可点 |
| 微信同步 | 清空按钮远离「开始同步」；本页不显示查看日期 |
| 系统设置 | 词表可停用；新增只保留禁用词。本页不显示查看日期 |

## 后端契约

- `GET /conversations`：`q`、`flag`；剔除公众号/安全中心等非客户；返回 timeout / forbidden / missing_media
- `GET /conversations/{id}`：单条带标记
- `GET /radar`：联系人名单与汇总；`start_date` / `end_date` / `status`
- `GET /metrics/overview`：`timeouts`、`hits`、`last_sync`、时长中文
- `GET /hits`：`contact`、`snippet`；噪音客户不出现
- `GET /analysis/results`：按 `start_date`/`end_date` 精确匹配；对不上则 `payload: null`
- `PATCH /lexicon/{id}`：只改 `enabled`
- 同步成功后自动跑规则扫描（失败不影响同步成功）
- 分析摘录带 `会话#{id} 客户:姓名`，并要求 JSON 回填 `conversation_id`、`contact`

## 不在本期

自动点开微信原图、语音转写、多客服账号、大屏看板。
