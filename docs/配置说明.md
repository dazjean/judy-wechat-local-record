# 配置说明

复制 `.env.example` 为 `.env`。

- `MODEL_BASE_URL` / `MODEL_NAME` / `MODEL_API_KEY`：客户自备 OpenAI 兼容接口。也可在页面「系统设置」填写，Key 不会回显。
- `TIMEOUT_SECONDS`：超时未回阈值，默认 180。
- `SESSION_GAP_HOURS`：会话切分间隔，默认 12。
- `JUDY_DATA_DIR`：可选。自定义数据目录（库文件、图片、诊断结果）。不填则用安装目录下的 `data/`。页面「系统设置」改目录会写入安装目录的 `data-dir.txt`，**重启后生效**，不会自动搬迁旧数据。环境变量存在时页面不能改。

监听地址固定建议 `127.0.0.1`，不要对局域网开放。
