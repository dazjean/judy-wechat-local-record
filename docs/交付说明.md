# 交付说明（实施内部，不发给客户）

客户拿到的是冻结后的 `Judy` 目录或 zip，不含 `backend/`、`frontend/src`、测试和签发私钥。

## 产品身份

- 正式名：Judy
- 副标题：本机微信会话分析
- 英文 / 发行名：Judy / `Judy`
- 版本：以 `backend/app/product.py` 为准

## 微信绑定

每套包在签发时写入 `license.dat`（Ed25519 签名）。运行时只核对本机微信**数据目录名**（脚本读到的那一行），对不上则拒绝同步、诊断和业务接口。不读库、不要求客户先做「微信读取初始化」。

复制安装目录给其他人：对方微信数据目录对不上，无法使用。这不是绝对防破解，目标是挡住直接转卖。

正式交付必须指定 `--wxid`（这里的值就是客户脚本发来的目录名，可以是 `wxid_…`，也可以是 `nxss11_c6ad` 这类非 wxid 目录名）。`--bind-on-first-use` 只在还拿不到目录名时备用。

`wxid_abc_00de` 这类带设备后缀的目录，签发时会去掉后缀。其它目录名按原样绑定。

## 交付前向客户要号

不要让客户发微信里「微信号」那一行的自定义号。把下面对应脚本发给客户即可：

- Windows：`scripts/get_wxid.bat`（双击）
- Mac：`scripts/get_wxid.sh`（拖到「终端」窗口后回车）

可原样发给客户：

```
交付前需要确认您电脑上登录的微信。请先打开并登录要用的那个微信，然后：

Windows：双击「get_wxid.bat」
Mac：把「get_wxid.sh」拖到终端窗口，按回车

弹出的窗口里，把「当前登录」下面那一行完整发给我。
脚本还会在同目录生成「本机wxid.txt」，把这个文件发我也行。

只发我个人，不要发到群里。
```

客户发来后，把「当前登录」那一行原样签发，不必要求一定是 `wxid_` 开头。带 `_00de` 的 `wxid_` 目录签发时会去掉后缀。

脚本只读微信数据文件夹名，客户不用先做「微信读取初始化」。同一微信号在不同电脑上目录名可能不同，要按那台交付机脚本读到的那一行签发。不要拿「其他账号目录」里的旧号签发。

仍拿不到时，不要盲发未绑定包。改为远程协助：当面用 `--bind-on-first-use` 打一包，看着客户用自己的微信完成「微信读取初始化」，确认系统设置里「本机系统号」已出现后再结束远程。

签发私钥：`packaging/keys/ed25519.pem`。只留在实施机，丢失则旧包无法再签新授权，只能换密钥并重新发版。

## 打包

与灵犀商用部署包同一口径：Nuitka 编译 `backend/app` + Tauri `Judy.app`（内嵌 python-build-standalone 3.12）+ ad-hoc 签名。须用 **CPython 3.12**。

本机首次还需要 Node、Rust（Tauri）。有可用的灵犀 Python 缓存时会复用，不必重新下载。

在客户将要运行的操作系统上执行（Windows 微信客户 → Windows 构建）：

```bash
python scripts/package.py --customer "庆总" --wxid 客户的wxid
```

多个 wxid：`--wxid a --wxid b`。限时：`--expires 2027-08-30`。

试用（对齐灵犀）：到期日 = 今天 + N 天，当天仍可用；页顶显示倒计时，到期锁屏。拨回系统日期也会结束试用。

```bash
python scripts/package.py --customer "庆总" --wxid 客户的wxid --trial-days 7
```

只签发授权：`python scripts/issue_license.py --customer "庆总" --wxid 客户的wxid --trial-days 7`。

试用转正：把正式 `license.dat` 放到解压目录（与 `Judy.app` 同级），覆盖试用，无需重装。解压根目录的授权优先于 App 内那份。

演练（不能发给客户）：

```bash
python scripts/package.py --customer "演练" --wxid nxss11_c6ad --skip-nuitka --skip-desktop
```

产出：

- `dist-release/Judy-1.0.0-<系统>-<客户>/`
- 同名 `.zip`

zip 根目录含 `Judy.app`、`install.sh`、`微信读取初始化.app`、《使用说明》，以及可写的 `data/`、`logs/`。`backend/`、`web/`、`license.dat`、运行脚本和读取组件都在 `Judy.app` 内，客户解压后看不到。发给客户的内容：上述目录或 zip。不要附带源码工程、`.venv`、`packaging/keys`、`docs/交付说明.md`、`docs/部署说明.md` 实施附录。

## 客户侧步骤

1. 安装并登录约定版本、约定账号的微信。
2. 解压到本机目录（不要放 iCloud / 网盘同步盘）。
3. 在解压目录运行 `bash install.sh`（清隔离并签名）。
4. 运行「微信读取初始化」。
5. 双击 **Judy.app**，在应用窗口中使用。
6. 在微信同步页确认就绪后同步。

关窗口会收到托盘，后台服务继续；要从托盘或 Dock **退出 Judy** 才会停掉本机服务。

换电脑：用同一微信重新初始化即可；换成另一个微信账号需要重新签发授权。

## 本机开发

没有 `license.dat` 时按开发模式放行。调试授权可把测试 `license.dat` 放到工程根目录，或设 `LINGXI_LICENSE_SKIP=1` 强制跳过。
