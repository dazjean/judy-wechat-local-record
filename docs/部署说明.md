# 部署说明

客户步骤以《使用说明》为准。生产包构建、微信绑定签发见 `docs/交付说明.md`（不对客户展示）。

## 客户步骤

1. 安装并登录约定版本的微信。
2. 解压后运行 `bash install.sh`，再运行「微信读取初始化」。
3. 双击 Judy.app，在应用窗口中使用。
4. 在「微信同步」确认就绪后同步近期会话。

换电脑后需重新做微信读取初始化。备份 `data/lingxi.db` 即可迁移分析结果。

---

## 实施附录（不对客户展示）

内部读取组件与灵犀帮聊相同，仅用于本机只读。

- 将组件放入 `vendor/` 或项目 `.venv`，不要写入系统 PATH。
- Windows 调用必须隐藏控制台（`CREATE_NO_WINDOW`）。
- 界面、报错、《使用说明》禁止出现 wechat-cli 等第三方名。
- Windows 微信基线 4.1.9.0；Mac 4.1+ 若 0 key 走既有适配器。
- 初始化成功后可用内部命令自检 `sessions` / `history`，不要让客户执行。
- 图片 / 语音 / 附件提取流程与能力边界见 `docs/媒体提取技术方案.md`。
