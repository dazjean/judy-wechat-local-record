## 一、卖什么

客户购买的是 **Judy 1.0 安装包的使用权**：在约定电脑、约定微信账号上，使用当前这一版的同步、统计、雷达、诊断能力。

- 授权绑定该电脑上的微信数据目录名（wxid 或脚本读到的目录名），**授权文件不设到期日**。
- 复制安装包到未授权微信无法使用。这是防转卖，不是年费开关。
- 微信客户端、操作系统或模型接口发生不兼容时，**不包含在本次费用内**。是否做新版本适配，另行评估，我方无强制更新义务。

## 三、标准交付清单（客户收到什么）

每成交一个计费单元，交付如下。**不交付源码工程。**

### 1. 软件包

- 对应操作系统的 Judy 安装目录或 zip（Mac 为 `Judy.app` 及解压目录内的 `install.sh`、`微信读取初始化`；Windows 为对应发行包）
- 已签发的授权文件（绑定本单约定的微信目录名，无到期日）
- 客户《使用说明》

客户包内不包含：`backend/`、`frontend/src`、测试代码、签发私钥、`docs/交付说明.md`、`docs/部署说明.md`、第三方读取组件名称与源码。

### 2. 可用功能（Judy 1.0）

在授权微信、本机环境下，客户可以使用：

| 模块 | 交付能力 |
|---|---|
| 微信同步 | 只读同步本机已登录微信的聊天记录；去重入库；任务进度与失败原因可见 |
| 客户雷达 | 按联系人看待回复 / 跟进 / 风险 / 沉寂等经营名单，点进对应会话（规则计算，不强制先跑模型） |
| 会话明细 | 按时间、超时、禁用词等筛选会话与消息 |
| 效率统计 | 首次响应、平均响应、超时未回；可按时间范围查看 |
| 诊断报告 | 选用提示词对选定范围做 AI 分析（高频问题、未闭环、关注会话、改进建议）；可查看本场景分析记录 |
| 提示词 | 编辑、新增分析场景（诊断报告提示词） |
| 群画像 | 本机群会话的基础画像查看 |
| 系统设置 | 本机昵称、模型地址 / 模型名 / API Key、超时与词表等；Key 只存在客户本机 |
| 导出 | 当前筛选范围导出（Excel / CSV） |
| 数据归属 | 聊天与分析结果保存在本机；本机按微信账号分桶，默认同步当前登录号 |

### 3. 实施服务（含在单号价款内）

- 交付前提供取号脚本，确认本机微信目录名后打包
- **一次**远程安装协助（解压、初始化、授权校验、完成一次同步试跑）
- 交付之日起 **30 天**内，修复本版本、本交付范围内的程序缺陷

### 4. 客户需自备

- 约定版本的微信客户端，并保持本单微信登录
- 用于 AI 诊断的模型 API（地址、模型名、Key）；无 Key 时规则统计与雷达仍可用，诊断报告不可用
- 安装目录使用本机固定磁盘，不要放在 iCloud / 网盘同步盘

## 四、验收标准（单号标准交付）

同时满足即可验收，不因客户未配置模型而否定整单（诊断报告除外）：

1. 在约定电脑、约定微信上，Judy 能完成一次微信同步，会话可在页面查看；
2. 客户雷达、会话明细、效率统计可打开并基于已同步数据展示；
3. 客户自行配置可用的模型 Key 后，能对选定范围跑出一份诊断报告；未配置 Key 时，页面能看到明确失败原因；
4. 授权微信不符时无法使用业务功能；拷贝到其他微信无法使用；
5. 已提供《使用说明》，并完成一次远程安装协助（或客户书面放弃协助）。

## 七、内部执行要点（不写入客户报价单）

- 打包在客户将要运行的操作系统上进行。
