## 一、合作目标

本方案不做单纯的聊天记录导出工具，而是先把以下完整闭环做出来：

> **安全获取客服聊天数据 → 整理结构化数据 → 调用客户自备 AI 模型进行分析 → 前端展示诊断结果 → 在真实客服场景中验证并迭代。**

系统采用源码交付方式。先在真实业务中共同完善；验证有效后，再按实际需求扩展更多管理、自动化和运营能力。

## 二、一期交付范围

### 1. 数据读取与本地整理

- 支持读取并整理多个客服账号的聊天记录；
- 对消息时间、发送方、会话、内容等基础字段进行结构化整理；
- 支持按账号、时间范围导出/筛选数据；
- 数据优先保存在庆总指定的电脑或部署环境中。

> **说明：**“不限制客服号”指一期系统的数据处理能力不按账号数量另行授权或收取账号费；实际部署需受电脑数量、微信环境、数据量和现场条件限制。超出约定的多台电脑部署、复杂环境排查或大量历史数据迁移，双方再单独确认工作量。

### 2. AI 分析能力

基于真实聊天数据完成基础分析链路，包含：

- 客服首次响应时长、平均响应时长、超时未回复统计；
- 客服沟通中的基础话术、禁用词/风险表达检测；
- 客户高频咨询问题归纳；
- 未解决问题、重复追问及需要关注的会话总结；
- 按客服/时间维度生成基础汇总结论与优化建议。

### 3. 前端结果展示

提供一期基础前端页面，用于查看：

- 数据导入/处理状态；
- 核心响应效率数据；
- AI 分析结果、问题摘要与建议；
- 按客服和时间范围筛选的基础结果。

一期以“清晰可用、能支持真实复盘”为标准，不以复杂大屏、完整商业化后台为交付目标。

### 4. 部署、验证与源码

- 在庆总指定环境中协助完成一次部署和真实数据验证；
- 提供一期源码、部署说明、配置说明及基础使用说明；
- 不设置机器码或账号授权限制；
- 对本方案验收范围内发现的问题进行修复和必要调整。

## 三、模型与数据安全边界

1. AI 分析所需的模型 API Key 由庆总自行申请、保管和配置；
2. 模型调用费用由庆总按实际用量直接向模型服务商结算，不包含在本项目报价中；
3. 我方不代管、不留存庆总的 API Key；
4. 聊天数据原则上在庆总指定环境处理，我方不作为长期数据保管方；
5. 本期以被动读取、整理和分析为主，不包含 AI 自动回复或主动发送消息。

## 四、本期不包含内容

为保证本方案按期交付，下列内容不在本报价内，后续按实际需求评估：

- AI 自动回复、自动发送消息或营销触达；
- 完整多角色权限体系、复杂实时看板、大屏；
- 人物画像、完整六维评分体系及复杂自定义评分规则；
- 企业微信、CRM、ERP 或其他第三方系统对接；
- 多电脑大规模部署、历史数据大规模迁移；
- 超出一期范围的新增功能、长期驻场或无限次迭代维护。

## 五、实施节奏与验收节点

| 阶段 | 主要工作 | 交付/验收结果 | 预计周期 |
|---|---|---|---:|
| P1：方案与数据链路 | 确认环境、数据格式、读取与整理链路 | 可读取并结构化输出样例数据 | 3～5 天 |
| P2：分析与前端 | 接入 AI 分析、完成核心结果页 | 可演示分析结果和基础前端页面 | 5～7 天 |
| P3：真实验证与交付 | 在指定环境试跑、问题调整、整理文档 | 真实数据验证通过，交付源码与文档 | 3～5 天 |

> 实际周期会受客户电脑环境、聊天记录获取方式、模型 API 开通情况及反馈确认效率影响。
